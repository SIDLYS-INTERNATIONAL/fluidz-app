We built it for ourselves. We're giving it to you.

A Chrome extension that adds a floating search panel to Grindr Web: highlight or filter grid profiles by name, find your favorites ★, auto-scroll the list. Nothing is automated on profiles, nothing is sent anywhere — it all stays in your browser.

Download for free See how it works
What it does

Find a profile in seconds

Grindr Web clears a card's content once it scrolls off-screen. Profile Hunter remembers it for you.

Search by name

Type a name or emoji (e.g. 🚀), several terms separated by commas. Highlight matches or hide everything else.

★ Favorites filter

Automatically detects profiles already favorited (the real Grindr icon, not a guess) and lets you list only those.

Auto-scroll

Scrolls the grid at an adaptive pace, and can stop itself the moment a new match shows up.

Bilingual FR / EN

The whole interface switches language in one click, and your choice is remembered.

The rule

Zero automation. Zero collection.

Profile Hunter never clicks a profile, favorites anything, or messages anyone on your behalf. It only reads what's already on your page, and helps you find your way through it.

✕
No network calls

The source code (content.js) contains no fetch, no HTTP call — checkable by anyone.

→
Everything stays local

Your searches and settings stay in Chrome's local storage, on your own device.

✕
No distance estimation

On purpose: we never try to infer the distance of a profile that chose to hide it.

→
Readable source code

No minification. Open content.js in a text editor if you want to check for yourself.

Installation

Two minutes, developer mode

Not on the Chrome Web Store yet — manual install, like any open-source extension.

1

Download and unzip

Grab the .zip below and unzip it somewhere on your computer.

2

Developer mode

Go to chrome://extensions and turn on developer mode, top right.

3

Load unpacked

Click "Load unpacked" and select the unzipped folder.

4

Open Grindr Web

Go to web.grindr.com (reload if needed) — the panel appears top right.
