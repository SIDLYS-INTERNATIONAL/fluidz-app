A Chrome extension that adds a floating search panel to Grindr Web: highlight or filter grid profiles by name, find your favorites ★, auto-scroll the list. Nothing is automated on profiles, nothing is sent anywhere — it all stays in your browser.

The real extension — search, favorites filter, hide mode, auto-scroll — running against a generated sample grid. Fictional names and stock/AI-generated photos: no real Grindr profiles were loaded or recorded.

What it does

Find a profile in seconds

Grindr Web clears a card's content once it scrolls off-screen. Profile Hunter remembers it for you.

Search by name

Type a name or emoji (e.g. 🚀), several terms separated by commas. Highlight matches or hide everything else.

★ Favorites filter

Automatically detects profiles already favorited (the real Grindr icon, not a guess) and lets you list only those.

Auto-scroll

Scrolls the grid at an adaptive pace, and can stop itself the moment a new match shows up.

Pinned shortcuts

Save any search as a one-click chip — 🚀 and ❄️ come pinned by default. Right-click a chip to remove it.

The rule

Zero automation. Zero collection.

Profile Hunter never clicks a profile, favorites anything, or messages anyone on your behalf. It only reads what's already on your page, and helps you find your way through it.

✕
No network calls

The source code (content.js) contains no fetch, no HTTP call — checkable by anyone.

→
Everything stays local

Your searches and settings stay in Chrome's local storage, on your own device.

✕
No distance estimation

On purpose: we never try to infer the distance of a profile that chose to hide it.

→
Readable source code

No minification. Open content.js in a text editor if you want to check for yourself.

Installation

Two minutes, developer mode

Not on the Chrome Web Store yet — manual install, like any open-source extension. Here's exactly what to click, screenshot by screenshot.

1

Download and unzip

Grab the .zip from the download section below and unzip it to a folder you'll remember — you'll need to point Chrome at that folder in step 3.

2

Open chrome://extensions and turn on Developer mode

Type chrome://extensions into Chrome's address bar and hit Enter. In the top-right corner, click the Developer mode toggle to switch it on (circled below) — three new buttons appear once it's on.

3

Click "Load unpacked"

Click the Load unpacked button that just appeared in the top-left (circled below). A file picker opens — navigate to the folder you unzipped in step 1, the one that directly contains manifest.json, and select it (select the folder itself, not a file inside it).

4

Confirm it's loaded and enabled

A "Profile Hunter" card appears in your extensions list. Make sure its toggle (bottom-right of the card, circled below) is switched on and blue.

5

Open Grindr Web

Go to web.grindr.com (reload the tab if it was already open) — the "🔎 Profile Hunter" panel appears in the top-right corner automatically, ready to search.
