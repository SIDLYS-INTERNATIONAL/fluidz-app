Installation

Two minutes, developer mode

Here's exactly what to click, screenshot by screenshot.

Why isn't it on the Chrome Web Store?

Grindr's terms are strict about third-party tools on its site. Profile Hunter never clicks, favorites or messages anyone — but it does scroll for you, and that grey zone is enough to keep it out of the official store.

So we ship it directly, and make it easy to trust: no data collected, no tracking, no network calls. Unzip it and every line of code is yours to read. As with any unofficial tool, use it at your own discretion.

1

Download and unzip

Grab the .zip from the download section below and unzip it to a folder you'll remember — you'll point Chrome at it in step 3.

2

Open chrome://extensions and turn on Developer mode

Type chrome://extensions in the address bar and hit Enter. Top-right, switch on Developer mode (circled below) — three new buttons appear.

3

Click "Load unpacked"

Click Load unpacked (top-left, circled below), then select the unzipped folder — the one that directly contains manifest.json. Select the folder itself, not a file inside it.

4

Confirm it's loaded and enabled

A "Profile Hunter" card appears in your extensions list. Make sure its toggle (bottom-right of the card) is on and blue.

5

Open Grindr Web

Go to web.grindr.com (reload the tab if it was already open) — the "🔎 Profile Hunter" panel appears top-right, ready to search.

FAQ

Before you install

Is it safe to install?

It's about 27 KB of plain, readable JavaScript. It only asks Chrome for local storage, only runs on web.grindr.com, and makes no network requests — nothing leaves your browser. Open content.js in any text editor to check.

Can it get my Grindr account in trouble?

We can't promise anything: it's an unofficial tool, and Grindr's terms are strict about those. What we can say is what it does — it never acts on a profile (no clicks, no favorites, no messages); it only searches and scrolls the page you're already looking at. Use it at your own discretion.

Does it work on my phone?

No — Chrome extensions only run on a computer. Use it with Grindr Web (web.grindr.com) on desktop. On your phone, leave your email now and open this page later on your computer.

Which browsers are supported?

Google Chrome. Other Chromium-based browsers that let you load an unpacked extension — Brave, Edge, Arc — should work the same way. Not Safari or Firefox for now.

Is it really free?

Yes. No paid plan, no account. We ask for an email so we can tell you about updates — and about Fluidz, the app we're building next.

How do I update it?

We'll email you when a new version is out. Replace the folder, click ↻ on the extension's card in chrome://extensions, then reload Grindr Web. Your searches and shortcuts are kept.
